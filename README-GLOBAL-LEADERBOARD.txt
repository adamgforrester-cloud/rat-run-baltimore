RAT RUN: BALTIMORE 1.0 — GLOBAL LEADERBOARD

THE GAME WORKS IMMEDIATELY
The included build runs with a polished local leaderboard. Music, sound effects,
the DOMINO SUGARS showcase, score milestones, champion alerts, and all gameplay
work without any additional setup.

TO SHARE SCORES ACROSS DIFFERENT PHONES AND COMPUTERS
A small online database must store the scores. This package includes a ready-made
Netlify Function for Supabase.

1. Create a free Supabase project.
2. In Supabase SQL Editor, run:

create table public.rat_run_scores (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 12),
  score integer not null check (score between 0 and 100000),
  session_id text not null unique,
  created_at timestamptz not null default now()
);

3. Deploy this project through a Git-connected Netlify site or the Netlify CLI.
   Netlify Functions need a function-capable deployment, not merely static hosting.
4. Add these Netlify environment variables:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
5. In leaderboard-config.js set:
   leaderboardApi: "/api/leaderboard"

IMPORTANT
Never place the Supabase service-role key inside index.html or leaderboard-config.js.
It belongs only in Netlify's protected environment variables.

The server validates player names, score range, and unique play-session IDs.
For a public competition, stronger anti-cheat validation can be added later.
