RAT RUN: BALTIMORE — DEPTH PROTOTYPE

Purpose
-------
This is a clean modular rebuild focused on the two biggest problems identified
in gameplay review:

1. The city felt flat and looked like stickers on graph paper.
2. The rats drifted rather than feeling alive.

Included
--------
- 30-second point-and-click rounds
- Working Supabase global leaderboard
- Perspective road that narrows toward the horizon
- Separate skyline, building, tree, sidewalk, curb, road, actor and effects layers
- Background rowhouses with restrained contrast
- Perspective-scaled sidewalk furniture
- Rats that dash, pause, zig-zag, accelerate and animate their legs
- Floating scores, particles, combo feedback and screen shake
- Large final ten-second countdown
- Modular files instead of one enormous HTML file

Deliberately excluded
---------------------
- Ghoul
- Police
- Gator
- Dogs
- Pedestrians
- Traffic

Those systems should return only after this base street and rat movement are
visually approved.
